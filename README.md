# Chicken Road Game

A simple browser-based game where you control a chicken crossing a busy road while collecting coins to earn money!

## How to Play

1. Open `index.html` in your web browser
2. Use **Arrow Keys** to move the chicken:
   - ⬅️ Left Arrow: Move left
   - ➡️ Right Arrow: Move right
   - ⬆️ Up Arrow: Move up
   - ⬇️ Down Arrow: Move down
3. **Collect coins** (💰) to earn money - each coin is worth $10
4. **Avoid vehicles** (cars and trucks) on the road
5. Try to travel as far as possible and collect as much money as you can!

## Features

- Real-time money counter
- Distance tracker
- Increasing difficulty (vehicles get faster over time)
- Game over screen with final score
- Restart functionality

## Running the Game

Simply open `index.html` in any modern web browser, or run a local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

Enjoy the game!
