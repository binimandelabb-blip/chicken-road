# chicken-road

A simple browser game built with HTML5 canvas. This repo contains a small "Chicken Road" game with a bilingual UI (Amharic and English) and a visible Telebirr donate number.

How to run locally
1. Save the files in a folder or clone the repo.
2. Open `index.html` in a modern browser (Chrome, Firefox).
3. Use arrow keys or WASD to move the chicken. Reach the top to score.

Hosting on GitHub Pages
- The files are on the `main` branch. To enable Pages:
  1. Go to the repository Settings -> Pages.
  2. Under "Source", choose the `main` branch and the root folder.
  3. Save. The site will be published at https://<your-username>.github.io/chicken-road/ (may take a minute).
